## Fluxo

- Configurações → Segurança → Alterar senha
- Senha atual + nova senha + confirmação
- Nova senha com mínimo de 8 caracteres
- Validação no servidor e Supabase Auth
- Mensagem de sucesso/erro sem expor detalhes sensíveis
- Recuperação por e-mail permanece no fluxo `/reset-password`

Asaas e dados de clientes/pagamentos não são alterados por este fluxo.
